# Dil Kursu Yönetim Sistemi

C# Windows Forms ile geliştirilmiş dil kursu yönetim sistemi.

## Özellikler
- Öğrenci kaydı
- Kayıt yönetimi
- Ana sayfa ve kurs işlemleri

## Kullanılan Teknolojiler
- C# / Windows Forms (.NET Framework)
- SQL Server LocalDB
- Visual Studio

## Kurulum
1. Repoyu indir (Code → Download ZIP).
2. SQL Server LocalDB'de KursDb adında bir veritabanı oluştur.
3. veritabani.sql dosyasını bu veritabanında çalıştır.
4. .slnx dosyasını Visual Studio ile aç ve çalıştır.
